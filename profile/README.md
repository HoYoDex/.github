HoYoDex indexes characters, lore, mechanics and data across Genshin Impact,
Honkai: Star Rail, Zenless Zone Zero, Honkai Impact 3rd, Tears of Themis and the
earlier Honkai titles — as one fast, searchable site.

**No ads. No trackers. No paywalls. No account needed to read anything.**

### Projects

| Repo | What it is |
|------|-----------|
| [**web**](https://github.com/HoYoDex/web) | The website — Astro 7 on Cloudflare Workers |

### Contributing

Two places, depending on what you want to fix:

- **Article content** — wrong facts, missing pages, typos → the
  [wiki](https://hoyodex.miraheze.org). Edits flow into the site automatically.
- **The site itself** — bugs, layout, features → [HoYoDex/web](https://github.com/HoYoDex/web/issues).
